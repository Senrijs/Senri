---
title: "Rate limiting"
description: "Limit the number of requests in a time window with rateLimit()"
---

```ts twoslash
import { createApp, rateLimit } from "@senrijs/senri";

const app = createApp();

app.use("/api", rateLimit({ windowMs: 60_000, limit: 100 }));   // 100 per minute
```

- Over the limit, the response is 429 with `Retry-After`
- It counts in fixed windows
- The default key is the client IP (per /64 for IPv6). Requests with an unknown IP are not limited, and a warning is printed the first time
- Behind a proxy, decide how to get the IP with [`trustProxy()`](/en/docs/request-response/request)

## Store

The default store is the process memory.

- With several processes or servers, each counts separately
- On Cloudflare Workers, the limit is per isolate, not global

To count globally, replace `store` with Redis or the like.
