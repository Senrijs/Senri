---
title: "リクエスト ID"
description: "requestId() で、リクエストに ID を付ける"
---

```ts twoslash
import { createApp, requestId, type RequestIdVariables } from "@senrijs/senri";

const app = createApp<RequestIdVariables>();

app.use(requestId());
app.get("/", (_, c) => `id: ${c.get("requestId")}`);
```

- リクエストごとに ID を作り、`c.get("requestId")` と、レスポンスの `X-Request-Id` に入れます
- ログやトレースで、同じリクエストを探すのに使います

## 受け取った ID を使う

受け取った `X-Request-Id` は、既定では使いません(だれでも付けられるため)。信頼できるプロキシの後ろでは、`trustIncoming: true` にします。 {/* verify: id */}

```ts twoslash
import { createApp, requestId } from "@senrijs/senri";
const app = createApp();
// ---cut---
app.use(requestId({ trustIncoming: true }));
```

128 文字までの `A-Z a-z 0-9 . _ = + / -` だけを受け付けます。それ以外は作り直します。 {/* verify: trust */}
