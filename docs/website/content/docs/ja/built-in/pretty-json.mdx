---
title: "JSON の整形"
description: "prettyJSON() で、?pretty を付けたときに JSON を整形する"
---

```ts twoslash
import { createApp, prettyJSON } from "@senrijs/senri";

const app = createApp();

app.use(prettyJSON());
app.get("/users", () => [{ id: 1, name: "alice" }]);
```

```bash
curl "http://localhost:3927/users?pretty"
# [
#   {
#     "id": 1,
#     "name": "alice"
#   }
# ]
```

- クエリに `pretty` があるときだけ整形します {/* verify: pretty */}
- 1 MiB を超える本文と、ストリームは整形しません
- `compress()` と `etag()` のあとに登録します
