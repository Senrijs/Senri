---
title: "Trailing slash"
description: "Normalize trailing slashes with trailingSlash()"
---

```ts twoslash
import { createApp, trailingSlash } from "@senrijs/senri";

const app = createApp();

app.use(trailingSlash());   // 301 from /a/ to /a
```

- `/a` and `/a/` already match the same route ([Path rules](/en/docs/routing/path-rules)). Use this to keep one URL form (for SEO)
- It redirects only GET and HEAD, and only paths that matched a route
