---
title: "末尾のスラッシュ"
description: "trailingSlash() で、末尾のスラッシュの形をそろえる"
---

```ts twoslash
import { createApp, trailingSlash } from "@senrijs/senri";

const app = createApp();

app.use(trailingSlash());   // /a/ → /a に 301
```

- `/a` と `/a/` は、もともと同じルートに当たります([パスの決まり](/docs/routing/path-rules))。URL の形を 1 つにそろえたいとき(SEO のため)に使います
- GET と HEAD で、ルートに当たったパスだけをリダイレクトします {/* verify: 301 */}
