どこからでも `c` を取る。

```ts
import { ... } from "@senrijs/senri/context-storage";
```

## 関数とクラス

| 名前 | すること |
| --- | --- |
| [`contextStorage()`](/docs/production/context-storage) | `c` を覚えるミドルウェア |
| [`getContext()`](/docs/production/context-storage) | いまの `c` を取る(なければ例外) |
| [`tryGetContext()`](/docs/production/context-storage) | いまの `c` を取る(なければ `undefined`) |
