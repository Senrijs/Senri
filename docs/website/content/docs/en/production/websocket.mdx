```ts twoslash
import { createApp } from "@senrijs/senri";
import { upgradeWebSocket } from "@senrijs/senri/websocket";

const app = createApp();

app.get(
    "/chat",
    upgradeWebSocket((c) => ({
        onOpen(ws) {
            ws.send(`hello ${c.query("name")}`);
        },
        onMessage(data, ws) {
            ws.send(data);       // data: string for text, Uint8Array for binary
        },
        onClose(code, reason, ws) {},
        onError(error, ws) {},   // also receives what the other handlers throw
    })),
);
```

Routes are written the same way on every runtime.

## What each runtime needs

| Runtime | Needs | Limit of one message |
| --- | --- | --- |
| Bun | Nothing with `serve()`. When you call `Bun.serve` yourself, pass `websocket` ([Bun](/en/docs/runtimes/bun)) | 16 MiB (Bun's default) |
| Deno | Nothing | Deno's default |
| Node.js | Install the `ws` package and pass it to `serve()` (below) | `maxPayload` of `ws` (the default is 100 MiB, so always set it) |
| Cloudflare Workers | Nothing | 1 MiB (the Workers limit) |
| Browser (Service Worker) | Not available (501) | |

```ts twoslash title="Node.js"
// @filename: types.d.ts
declare module "ws" {
    export const WebSocketServer: any;
}
// @filename: index.ts
import { createApp } from "@senrijs/senri";
const app = createApp();
// ---cut---
import { WebSocketServer } from "ws";
import { serve } from "@senrijs/senri/serve";   // serve() from @senrijs/senri/node works the same

await serve(app, { webSocketServer: new WebSocketServer({ noServer: true, maxPayload: 1024 * 1024 }) });
```

On Node.js, Senri does not parse WebSocket frames itself: it leaves them to the proven `ws` (Senri gets no new dependencies).

- Without `webSocketServer`, WebSocket routes return 500 (development mode shows how to pass it)
- In development mode, a notice is printed on start if the `maxPayload` of the `WebSocketServer` you passed is still the `ws` default (100 MiB)

## What it protects

- **Connections from pages on other sites are rejected with 403 by default** (against Cross-Site WebSocket Hijacking). Only connections whose `Origin` host matches `Host` pass. Add other origins with `upgradeWebSocket(create, { origin: ["https://app.example.com"] })`. Connections without `Origin` (not from a browser) pass
- Middleware runs the same as for normal requests. If authentication middleware returns 401, there is no upgrade
- Requests without `Upgrade: websocket` get 426

Negotiating subprotocols (`Sec-WebSocket-Protocol`) and configuring compression (permessage-deflate) are not supported yet.
