---
title: "Timeout"
description: "Return 504 with timeout() if a request does not finish in time"
---

```ts twoslash
import { createApp, timeout } from "@senrijs/senri";

const app = createApp();

app.use("/api", timeout(5000));   // 504 if not finished in 5 seconds
```

## What it does not stop

Even after it returns 504, the handler's work itself does not stop.

- During a synchronous loop, the timer does not run either
- `c.req.signal` only means the client disconnected
- To stop calls to other services, combine it with `AbortSignal.timeout()`

```ts twoslash
import { createApp, timeout } from "@senrijs/senri";
const app = createApp();
// ---cut---
app.use("/api", timeout(5000));
app.get("/api/slow", async () => {
    const res = await fetch("https://example.com/slow", { signal: AbortSignal.timeout(5000) });
    return res.text();
});
```
