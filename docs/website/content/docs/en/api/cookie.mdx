```ts
import { ... } from "@senrijs/senri/cookie";
```

## Functions and classes

| Name | What it does |
| --- | --- |
| [`getCookie(c, name?)`](/en/docs/request-response/request) | Reads one cookie, or all of them |
| [`setCookie(c, name, value, options?)`](/en/docs/request-response/request) | Sets a cookie |
| [`deleteCookie(c, name, options?)`](/en/docs/request-response/request) | Deletes a cookie |
| [`setSignedCookie(c, name, value, secret, options?)`](/en/docs/request-response/request) | Signs and sets a cookie |
| [`getSignedCookie(c, name, secret)`](/en/docs/request-response/request) | Verifies and reads a signed cookie |
