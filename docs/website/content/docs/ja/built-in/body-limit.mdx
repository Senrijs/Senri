---
title: "本文の大きさの上限"
description: "bodyLimit() で、ルートの本文の上限を決める(既定の 1 MiB を置き換える)"
---

```ts twoslash
import { bodyLimit, createApp } from "@senrijs/senri";

const app = createApp();

app.use("/import", bodyLimit({ maxSize: 50 * 1024 * 1024 }));   // このルートだけ 50 MiB まで
```

- 超えたら 413 を返します
- アプリの既定の上限(1 MiB)を**置き換えます**。重ねないので、既定より大きくも小さくもできます
- Content-Length があれば、読む前に断ります。ない(チャンク転送)ときは、読みながら数えます
- `c.req.body` をストリームで流すルートにも効きます
- `maxSize` は有限の数で書きます。上限をまったく付けたくないときは、`createApp({ maxBodySize: Infinity })` を使います {/* verify: finite */}

本文の上限の全体の話は、[本文の読み方と上限](/docs/request-response/body)にあります。

## 超えたときの応答を変える

```ts twoslash
import { bodyLimit, createApp } from "@senrijs/senri";
const app = createApp();
// ---cut---
app.use("/import", bodyLimit({ maxSize: 1024 * 1024, onError: () => ({ error: "too large" }) }));
```

`onError` を呼ぶ前に status を 413 にしてあるので、文字列やオブジェクトを返すと 413 で送ります。`Response` を返したときは、その status のままです。 {/* verify: 413 */}
