# {{name}}

A [Senri](https://github.com/Senrijs/Senri) app for Node.js (22.18 or later, which runs TypeScript files directly).

```bash
npm install
npm run dev     # http://localhost:3927 (restarts when you edit a file)
npm start
```

Open http://localhost:3927/_senri to see requests in the dev dashboard.
